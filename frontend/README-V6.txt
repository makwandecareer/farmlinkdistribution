FarmLink Administration Centre V6 — World-Class Provincial Edition

This package upgrades the existing V5 admin portal without removing any working API endpoints.

Included:
- Differentiated executive KPI cards
- Formal South African province filters
- Province columns for farmers and buyers
- Automatic province normalization
- Provincial coverage dashboard across all 9 provinces
- Improved account role presentation
- Precision alignment and responsive refinements
- Existing approval, rejection, administrator, finance, inventory, logistics, quality, documents and audit functions preserved

Installation:
Copy the included frontend/admin folder over E:\farmlink-production\frontend\admin
Then commit and push the three admin files.
