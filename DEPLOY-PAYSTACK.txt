FarmLink Paystack Production Integration

WHAT THIS PACKAGE DOES
----------------------
1. Initializes Paystack transactions from the FastAPI backend.
2. Determines the charge amount on the server, never from browser input.
3. Redirects customers to Paystack-hosted checkout.
4. Verifies reference, amount, currency and transaction status server-side.
5. Validates Paystack webhooks with HMAC SHA-512.
6. Returns webhook HTTP 200 quickly and verifies in a background task.
7. Creates/updates FarmLink Payment records automatically.
8. Updates invoices, paid memberships and paid orders.
9. Adds a responsive payment-success callback page.
10. Connects paid membership applications to secure checkout.

IMPORTANT SAFETY RULE
---------------------
Use Paystack TEST keys first. Do not switch to live keys or accept real money
until initialization, callback, webhook, duplicate handling and admin payment
records have all been tested end-to-end.

git push origin main

VERIFY IN SWAGGER
-----------------
https://farmlinkdistribution.onrender.com/docs

Look for:
POST /api/payments/paystack/initialize
GET  /api/payments/paystack/verify/{reference}
GET  /api/payments/paystack/status/{reference}
POST /api/payments/paystack/webhook

TEST FLOW
---------
1. Keep Paystack in Test Mode.
2. Submit a paid membership application.
3. Accept the prompt to continue to Paystack.
4. Complete a Paystack test payment.
5. Confirm payment-success.html shows Payment verified.
6. Confirm Payment Records and Finance Centre show the payment.
7. Confirm the webhook receives HTTP 200.
8. Test cancellation and failed payment.
9. Only after all checks pass, replace test keys with live keys.
